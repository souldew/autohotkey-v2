AutoHotkey キーマップ

main.ahk で読み込んでいる設定（henkan_layer.ahk・muhenkan_mouse.ahk・xbutton1_hscroll.ahk）を JIS 配列の上に描いたもの。キーの左上が元のキー、下が押したときの動作。

mouse/xbutton1_hscroll.ahk

操作動作

XButton1 ＋ ホイール上左へ横スクロール
XButton1 単押し戻る

QMK Firmware の Mouse Keys

QMK の Mouse Keys は、キーボードでマウスを操作するためのキーコードと動き方を決めた機能。どのキーに置くかの配置は決めていないので、図ではなく、使える機能を並べる。

機能キーコードmuhenkan_mouse.ahk での対応
カーソル移動（上下左右）MS_UP・MS_DOWN・MS_LEFT・MS_RGHTE・D・S・F
クリック（ボタン 1〜8）MS_BTN1〜MS_BTN8左・右・中クリックのみ
ホイール（上下左右）MS_WHLU・MS_WHLD・MS_WHLL・MS_WHLR上下のみ（左右は無い）
速度の切り替え（3 段階）MS_ACL0・MS_ACL1・MS_ACL2無し（押し続けた時間で加速）
  • 動き方のモード: 押し続けると速くなる Accelerated（既定）、加速が二次曲線の Kinetic、一定速度の Constant、Accelerated に速度固定キーを足した Combined、離したあとも少し滑る Inertia。
  • muhenkan_mouse.ahk は、Miryoku と同じく Accelerated（押し続けると速くなる）にならっている。
